# Homelab

My personal homelab running on a CachyOS desktop, managed with Docker Compose.

## Services

| Service     | Port | Purpose                    |
|-------------|------|----------------------------|
| Uptime Kuma | 3001 | Uptime monitoring          |
| Homepage    | 3000 | Dashboard for all services |

## Usage

```bash
docker compose up -d
```
